# zen2han

全角の数字・英字・記号・スペースを、半角に変換するコマンドです。標準入力から読み込み、変換した結果を標準出力に出します。全角と半角が混ざった文章やデータ（住所やCSVなど）を、半角にそろえたいときに使えます。ひらがな、カタカナ、漢字は変換しません。
## 動作環境


- OS: Ubuntu 24.04
- Python: 3.12

## インストール

```
$ git clone https://github.com/Ryuhei06/zen2han.git
$ cd zen2han
$ chmod +x zen2han

```


どのディレクトリからでも使いたい場合は、`~/bin` にコピーして、PATHを通します。

```
$ mkdir -p ~/bin
$ cp zen2han ~/bin/
$ echo 'export PATH="$HOME/bin:$PATH"' >> ~/.bashrc
$ source ~/.bashrc
```
## 使い方

標準入力から読み、標準出力に出します。

```
$ echo "東京都墨田区１－２－３" | ./zen2han
東京都墨田区1-2-3
```　

ファイルを変換するときは、リダイレクトを使います。

```

$ printf '１\n２\n' > input.txt
$ ./zen2han < input.txt > output.txt
$ cat output.txt
1
2

```
## オプション

- オプションなし: 数字、英字、記号、全角スペースを、すべて変換する
- `-d`: 数字だけ変換する
- `-a`: 英字だけ変換する
- `-s`: 記号と全角スペースだけ変換する
- 組み合わせられる（例: `-d -a`）

```
$ echo "１Ａ！" | ./zen2han -d
1Ａ！
$ echo "１Ａ！" | ./zen2han -a
１A！
$ echo "１Ａ！" | ./zen2han -s
１Ａ!
```

## 変換する文字としない文字

- 変換する: 全角の数字（０〜９）、英字（Ａ〜Ｚ、ａ〜ｚ）、記号（！？（）－ など）、全角スペース
- 変換しない:  ひらがな、カタカナ、漢字、半角カナ、長音（ー）

## 終了ステータスとエラー

- 正常に終わると、終了ステータスは 0
- 未知のオプションを付けると、標準エラー出力にメッセージを出し、終了ステータスは 2（標準出力には何も出ない）
- UTF-8でない入力では、標準エラー出力にメッセージを出し、終了ステータスは 1
